# 🖥️ 租服务器 + 部署在线版（完整教程）

把 `web-version` 跑在云服务器上，公网就能访问"实时爬数据"的音乐剧工具。
本文分两部分：**① 怎么租服务器**（约 10 分钟）→ **② 怎么部署**（约 5 分钟，一条命令）。

---

## 一、租服务器

### 1.1 先想清楚要什么

这个项目只需要：**一台能跑 Node.js 的 Linux 小机器**（2 核 2G 足够，甚至 1 核 1G 也能跑）+ 可以访问外网 + 对公网开放一个端口。

### 1.2 选国内还是海外（关键决策）

| | 国内服务器（阿里云/腾讯云轻量） | 香港/海外（阿里云香港、Vultr、Hetzner 等） |
|---|---|---|
| 价格 | 新用户优惠后约 **¥40-60/月** | 香港约 ¥24/月起；海外低至 €4/月 |
| 域名/备案 | **必须备案**才能用 80/443 端口；**不备案可用其他端口**（本项目用 8878，免备案） | **无需备案**，随便绑域名 |
| 访问速度 | 国内访问快 | 香港快；欧美稍慢 |
| 爬取效果 | 国内 IP 访问大麦/猫眼网络好，但反爬照旧 | 海外 IP 可能被平台风控更严（大麦对海外 IP 常直接拦） |

> **给本项目（爬虫）的建议**：选**国内轻量服务器 + 用 8878 非标准端口**（免备案、爬取网络好），
> 不要用 80/443 端口、不绑域名，就完全不需要备案。

### 1.3 具体买哪台（推荐清单）

- **预算优先**：腾讯云 / 阿里云 **轻量应用服务器 · 2核2G · Ubuntu 22.04**，新用户首年常有大促（¥40-60/月档）。
- **免备案**：同上的**香港地域**轻量（约 ¥24-30/月，新用户更低）。
- **国外便宜**：Hetzner CX22（€4.5/月，需外币卡）、Vultr $6/月、DigitalOcean $6/月——只推荐给有一定折腾经验的人。

### 1.4 购买步骤（以腾讯云轻量为例，其它厂商类似）

1. 打开腾讯云官网 → 搜索「**轻量应用服务器**」→ 点「新建」；
2. 地域：选「**中国香港**」（免备案）或国内（需按 1.2 注意端口）；
3. 镜像：选「**Ubuntu 22.04 LTS**」系统镜像（不要选带宝塔面板的，除非你想用面板）；
4. 套餐：**2 核 2G**（或按预算最小档）；
5. 设置**服务器密码**（或选密钥，新手用密码简单）；
6. 确认购买（新用户通常有 1-3 个月优惠价，注意到期续费价）。

### 1.5 购买后：放行端口（最重要的一步！）

- 轻量服务器控制台 → 「**防火墙**」或「**安全组**」→ **添加规则**：
  - 协议 TCP，端口 **8878**，来源 0.0.0.0/0（允许所有人访问）
  - （22 端口 SSH 一般默认已放行）
- 不放行的话，网页会打不开（这是新手最常踩的坑）。

## 二、部署（两条命令）

### 2.1 登录服务器

Windows 打开 **PowerShell** 或 **终端**：

```bash
ssh root@你的服务器IP
```

输入刚才设置的密码（输入时不显示字符，正常现象）。第一次登录会提示确认指纹，输入 `yes`。

### 2.2 一键部署

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/lzd1221/musical-calendar/main/web-version/deploy/deploy.sh)"
```

脚本会自动：安装 Node 20 → 拉取最新代码 → 创建专用用户 → 注册 systemd 服务（开机自启、崩溃自动重启）→ 放行端口。**约 2-3 分钟**完成后，浏览器打开：

```
http://你的服务器IP:8878
```

就是完整的"在线实时爬"版了（和本地 8878 完全一样）。

### 2.3 访问密码（部署后默认已开启）

打开 `http://IP:8878` 会先要求输入**访问密码**（登录后 7 天免登录）：
- 默认密码：`musical2025`
- 修改：编辑 `/opt/musical-calendar/web-version/sources/config.js` 的 `PASSWORD` 字段 → `sudo systemctl restart musical-web`
- 服务器上请务必改成你自己的强密码！

### 2.4 常用维护命令

```bash
sudo systemctl status musical-web      # 服务状态
sudo journalctl -u musical-web -f      # 实时日志（看爬取报错）
sudo systemctl restart musical-web     # 重启
```

## 三、上线后要做的几件事

1. **改 root 密码为强密码**（控制台可重置），不要用弱密码；
2. **测试搜索**：搜一部剧，看 360/必应兜底是否正常；数据中心 IP 访问平台可能被风控更严，属正常；
3. **提高抓取成功率（可选）**：编辑 `/opt/musical-calendar/web-version/sources/config.js` 填 `COOKIE`（浏览器登录平台后复制），然后 `sudo systemctl restart musical-web`；
4. **更新代码**：`cd /opt/musical-calendar && sudo -u musical git pull && sudo systemctl restart musical-web`（或重跑一次 deploy.sh）；
5. **省钱提醒**：轻量服务器到期不续费会被回收数据，重要数据记得本地导出（手动录入在服务器浏览器 localStorage，与本地不互通——这是设计如此）。
