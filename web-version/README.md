# 🎭 音乐剧排期 & 抢票日历 · 网页版（本地服务）

输入**剧名（+ 城市 + 年份）→ 自动上网爬取相关信息**的网页版。爬不到时会明确提示每个来源的状态和原因。

> 与 GitHub Pages 在线版（纯静态、不能爬）不同，本版本在本机跑一个 Node 服务，
> 由服务端真实请求票务平台和搜索引擎（浏览器直连会被 CORS 和反爬拦截，服务端可以）。

## 启动方法

```bash
node web-version/server.js
```

然后浏览器打开 **http://localhost:8765**

> 需要本机装有 Node.js（v16+）。Windows 下直接双击 `启动网页版.bat` 也可以。

## 爬取逻辑（多源 + 兜底）

| 来源 | 方式 | 现状 |
|---|---|---|
| 大麦 Damai | 服务端直连搜索接口 + 详情页抓开售时间 | 多数网络下被 x5sec 反爬拦截 |
| 猫眼 Maoyan | 服务端直连搜索接口 | 多数网络下被 WAF 拦截 |
| 保利票务 / 摩天轮 / 票牛 | 候选接口并行尝试 | 接口不稳定，多为失败 |
| **360 搜索（主兜底）** | 搜索「"剧名" 年份 城市 演出 开票」解析结果 | ✅ 实测可用，相关性好（开票新闻/票务页/演出信息） |
| **必应搜索（次兜底）** | 同上，360 为空时启用 | 间歇性反爬限流 |

**合并与去重**：票务平台命中的按「剧名+城市+年份」合并，多平台渠道聚合展示。
**失败提示**：每个来源都有状态徽标（✅/⛔+原因）；全部失败时给出提示 + 必应/360 参考链接 + 手动录入入口。

## 数据与隐私

- 全部请求由**你本机的 Node 服务**发出，数据仅保存在本机（手动录入存浏览器 localStorage）。
- 无任何第三方服务、无云端依赖；关闭页面/服务即停止抓取。
- 请勿高频连续搜索（平台反爬会限流），建议每次搜索间隔 10 秒以上。

## 可调参数

- 端口：`set PORT=9000` 后启动，或 `PORT=9000 node web-version/server.js`
- 数据源开关 / Cookie：`web-version/sources/config.js`（如需绕过平台 WAF，可填入浏览器登录后的 Cookie）

## 与其它版本的关系

- `musical-calendar.html` / GitHub Pages 在线版：纯手动 + 示例数据，离线可用，不能爬。
- `web-version/`（本目录）：**能爬**，需要本机 Node。
- `wechat-miniprogram/`：小程序版（云函数爬取 + 订阅消息推送），需要微信开发者工具部署。
