# 🎭 音乐剧排期 & 抢票日历

帮你**最大限度看全想看的音乐剧**：管理剧目与场次排期、检测**撞期**和**与上班时间冲突**、
**抢票倒计时提醒**、一键生成**不撞期且不影响上班的最优看剧计划**。

本项目包含 **三个版本**，按你的使用场景选一个：

| 版本 | 地址 | 能自动爬数据吗 | 适合 |
|---|---|---|---|
| ① 离线版 | https://lzd1221.github.io/musical-calendar/ | ❌ 手动录入 | 随手规划、离线可用 |
| ② 本地爬虫网页版 | 本地 `http://localhost:8878` | ✅ 能（360/必应 + 深度解析） | **日常主力**，填剧名自动获取信息 |
| ③ 微信小程序版 | 需微信开发者工具部署 | ✅ 能（云函数） | 手机端、开票/开演推送提醒 |

## ② 本地爬虫网页版（推荐日常使用）

**填剧名 → 自动上网爬相关信息（购票平台 / 开票时间 / 场次 / 场馆 / 票价），爬不到会明确提示。**

### 启动方法

```bash
node web-version/server.js
```

然后浏览器打开 **http://localhost:8878**

> Windows 也可以直接**双击 `web-version\启动网页版.bat`**（自动打开浏览器）。
> 需要本机装有 Node.js v16+（`node -v` 查看）。端口被占用时会自动顺延，按提示的地址访问即可。

### 怎么用（详细步骤）

**第 1 步：输入剧名（有联想）**
- 输入**第一个字**即弹出下拉联想（内置 80+ 常见剧目：音乐剧/舞剧/话剧，含中英文名）
- 键盘 ↑↓ 选择、**回车确认**，或鼠标直接点选；点选后自动开始搜索
- 词库在 `web-version/public/index.html` 顶部的 `SHOWS` 数组，可自行增补

**第 2 步：点选城市**
- 城市为**点选标签**（上海/北京/广州/深圳/杭州/南京/苏州/成都/重庆/武汉/西安/长沙/天津/青岛/其他）
- 点击即选中并高亮，**上次选择会自动记住**

**第 3 步：选年份（可选）** → 点「🔍 搜索」或直接回车

**第 4 步：看结果**
- **来源状态徽标**：每个数据源显示 ✅（成功，含数量）或 ⛔（失败，附原因）
- **平台命中**：若大麦/猫眼等返回数据，显示剧目卡片（购票链接/开票倒计时/场次/其他渠道）
- **相关网页参考**：360 搜索（主）或必应（备）发现的开票新闻/票务页/演出信息
- **深度解析**：自动抓取参考网页正文，直接提取并高亮显示：
  - 🎫 **开票时间**（页面写明时刻时）
  - 📍 **场馆**　💰 **票价**　📅 **演出场次日期**
- **底部提示**：明确告诉你这次爬取的结果和下一步建议

**爬不到怎么办？**
- 平台直连被反爬拦截属正常（大麦 x5sec / 猫眼 WAF），系统会自动走搜索引擎 + 深度解析兜底
- 仍没有 → 页面提供**手动录入**表单（开票时间/链接/场次），保存在本机浏览器
- 想要更强的直连成功率：编辑 `web-version/sources/config.js`，把浏览器登录平台后的 `COOKIE` 填进去（低频个人使用）

### 数据与隐私

- 所有抓取由**你本机**的 Node 服务发出；手动录入存本机浏览器 localStorage
- 无第三方服务、无云端依赖；关闭页面即停止
- 请勿高频连续搜索（平台反爬会限流），建议每次搜索间隔 10 秒以上

### 配置项

| 项 | 说明 |
|---|---|
| 端口 | `PORT=9000 node web-version/server.js`（默认 8878，被占用自动顺延） |
| 数据源开关 | `web-version/sources/config.js`：`ENABLE_DAMAI` 等逐个开关 |
| Cookie | 同上文件 `COOKIE` 字段，可选 |
| 详细文档 | 见 `web-version/README.md` |

## ① 离线版（零依赖，双击即用）

单文件 HTML 工具，无需安装、无需联网，**数据存浏览器本地**。

### 打开方式

- **在线**：https://lzd1221.github.io/musical-calendar/ （GitHub Pages，手机/电脑均可）
- **本地**：双击 `musical-calendar.html`（或 `index.html`，两者内容一致），拖进 Chrome/Edge

### 使用流程

1. **添加剧目**：点「＋ 添加剧目」→ 填剧名、优先级（必看 > 想看 > 可选）、城市
2. **录入场次**：点「＋场次」→ 日期 / 开始时间 / 结束时间 / 场馆 / **开票时间**（留空=未公布）
3. **看日历**：月历总览所有场次；**红色描边 = 撞期或与上班时间冲突**；🎫 = 当天开票；点任意一天看详情
4. **抢票提醒**：「🎫 抢票」页显示所有开票时间**秒级倒计时**；开票前 5 分钟**浏览器通知** + 开票瞬间提示音（需保持页面打开并在设置里开启通知）
5. **智能排期**：点「⚡ 生成排期」→ 自动算出**优先级总分最大、互不撞期、避开上班时间**的最优看剧计划，支持同一天午场+晚场「连打」，并说明每部未排入剧目的原因
6. **数据管理**：设置页可 JSON 导出/导入备份、导出 iCal 日历（同步到手机日历）、载入示例数据、清空数据

### 功能一览

| 页面 | 功能 |
| --- | --- |
| 📅 日历 | 月历总览、撞期/上班冲突标红、当天开票标记、点击看详情 |
| 📋 剧目 | 剧目管理（优先级/城市/类型/可请假）、多场次录入、搜索筛选 |
| 🎫 抢票 | 开票时间实时倒计时、浏览器通知+提示音、已抢/已购/放弃标记 |
| 🧭 智能排期 | DP 最优解排期（必看 3 分 > 想看 2 分 > 可选 1 分）、锁定已购场次、避开上班时间、连打提示 |
| ⚙️ 设置 | 上班时间自定义、通知开关、JSON 备份恢复、iCal 导出、示例数据 |

### 智能排期算法说明

- 每部剧最多安排一场；目标 = 所看剧目**优先级总分最大化**
- 按结束时间排序的动态规划（`dp[mask] = 该集合的最小最后结束时间`）保证最优解；剧目 >18 部时自动退化为贪心（更快）
- 已「已抢/已购」的场次默认锁定；剧目勾选「可请假」后工作日场次可参与排期

## 常见问题（FAQ）

**Q：在线预览版能爬数据吗？**
A：不能。GitHub Pages 是纯静态托管，没有后端跑不了爬虫；且浏览器直连票务平台会被 CORS + 反爬拦截。在线版 = 手动录入 + 示例数据。**要爬数据请用本地网页版（②）**。

**Q：本地网页版搜索显示所有来源都是 ⛔？**
A：平台直连被反爬拦截是正常现象，此时会自动走 360/必应 + 深度解析兜底；若深度解析也未命中，按页面提示稍后再试（搜索引擎有限流）或手动录入。

**Q：开票时间抓不到？**
A：只有页面**明确写明"开票时间：X月X日 XX:XX"**时才能提取；很多官宣只写"现已开票"无具体时刻，这类抓不到。可手动录入补全。

**Q：数据会同步吗？**
A：离线版和网页版手动录入存在各设备浏览器 localStorage（不互通）；小程序版数据在云端（所有设备同步）。跨版本不互通，属设计如此。

**Q：想用公网在线版 + 实时爬？**
A：把 `web-version/server.js` 部署到 VPS（腾讯云轻量等）即可，两条命令跑起来，见 `web-version/README.md`。
