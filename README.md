# 🎭 音乐剧排期 & 抢票日历

> 🖥 **在线预览**：https://lzd1221.github.io/musical-calendar/ （GitHub Pages，手机/电脑浏览器直接打开）

一个**零依赖、双击即用**的单文件网页工具：管理你想看的音乐剧及其场次排期，
自动检测**撞期**与**与上班时间冲突**的场次，提供**抢票倒计时提醒**，
并一键生成**不撞期、不影响上班、优先级最大化**的最优看剧计划。

## 快速开始

1. 用浏览器直接打开 `musical-calendar.html`（Chrome / Edge 均可，无需联网、无需安装）。
2. 点「✨ 载入示例数据」看效果，或从「📋 剧目」页开始添加你自己的剧目。
3. 所有数据保存在浏览器本地（localStorage），换浏览器/清缓存前记得在「⚙️ 设置」里导出备份。

## 功能一览

| 页面 | 功能 |
| --- | --- |
| 📅 日历 | 月历总览；红色描边 = 撞期或与上班时间冲突；🎫 = 当天开票；点击任意一天查看详情与冲突原因 |
| 📋 剧目 | 添加剧目（名称/优先级/城市/类型），为每部剧录入**多个场次**（日期/时间/场馆/开票时间）；支持搜索与筛选 |
| 🎫 抢票 | 所有开票时间实时倒计时（精确到秒）；开票前 5 分钟**浏览器通知** + 开票瞬间提示音；快速标记 已抢/已购/放弃 |
| 🧭 智能排期 | 一键算出最优看剧计划：**最大化优先级总分**、场次互不撞期、默认避开工作日上班时间、支持同一天午场+晚场「连打」 |
| ⚙️ 设置 | 自定义上班时间（周几/几点到几点）、通知开关、JSON 备份/恢复、导出 iCal 日历（可导入手机日历） |

## 智能排期怎么算

- 每部剧最多安排一场；目标 = 所看剧目的**优先级总分最大化**（必看 3 分 > 想看 2 分 > 可选 1 分）。
- 算法：按结束时间排序的动态规划（`dp[mask] = 该集合的最小最后结束时间`），保证最优解；
  剧目 ≤ 18 部时自动用最优解，更多时退化为贪心（更快）。
- 已标记「已抢/已购」的场次默认**锁定**，其余场次自动避让。
- 可在剧目上勾选「可请假」，该剧的工作日场次即可参与排期。
- 排期结果会说明每部未排入剧目的具体原因（未排期 / 场次都在上班时间 / 与哪些场次撞期）。

## 小贴士

- 开票时间不确定的场次可以留空，等官宣后再补；「汉密尔顿」这类未排期的剧可以只建剧目不建场次。
- 周末下午场 + 当晚场常常能一天看两部，排期结果会自动标出「🎉 同日连打」。
- 抢票提醒需要：页面保持打开 + 在设置里开启通知并允许浏览器权限。
- 想同步到手机日历：设置页导出 iCal 演出日历 / 抢票提醒，用手机邮箱或日历 App 导入即可。

## 微信小程序版（推荐日常使用）

仓库中 `wechat-miniprogram/` 是本工具的**微信小程序版本**（云开发 + 订阅消息推送）：

- 输入「剧名 + 年份 + 城市」**自动获取**大麦/猫眼等平台的抢票链接、开票时间、场次排期；
- 关注剧目后自动排日历、提示撞期与上班冲突；开票前/开演前**微信订阅消息主动推送**；
- 抓取失败时手动补录，数据全用户共享兜底；
- 部署步骤（AppID / 云开发环境 / 订阅消息模板 / 云函数上传）见 `wechat-miniprogram/README.md`。

> 本 HTML 单文件版 = 离线规划；小程序版 = 联网自动获取 + 推送提醒，两者配合使用。
