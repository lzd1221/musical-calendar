## ✨ 核心功能（多用户版）

### 1. 账户系统
- 注册 / 登录（密码 scrypt 加盐哈希存储，不存明文）
- 登录态 HMAC 签名 token（cookie 7 天有效），数据按用户隔离、**跨设备同步**

### 2. 个人日历
- 月历视图：每个日期标记 **🎫 抢票（红）** 和 **🎭 看剧（金）**
- 点击月份切换 / 回今天
- 剧名超长自动换行

### 3. 剧目搜索（多数据源并行）
| 数据源 | 状态 | 说明 |
|---|---|---|
| 官方·上海文化广场 | ✅ | 微信 UA 抓取官方节目列表（15+ 节目） |
| 官方·上海大剧院 | ✅ | 冷离票务接口 + cmpappkey 认证（9+ 节目） |
| 社区共享 | ✅ | 用户公开的抢票/开场信息 |
| 大麦 / 猫眼 / 保利 / 二手 | ⛔ | 被平台反爬拦截（预期内） |
| 360 / 必应搜索 | ⚠️ | 云服务器 IP 被限流，兜底用 |

- 剧名输入**一字联想下拉**（60+ 剧目词库，↑↓+回车/点选）
- 城市**点选标签**（记住上次选择）
- 搜索结果带剧名/类型/价格/场次/购票链接，**一键加入日历**

### 4. 一键加入日历（带全部场次）
- 搜索到演出 → 加入日历时**自动带出该剧全部场次**（如《太阳王》34 场全部铺进日历）
- 自动填充剧名、城市、开票时间、场次、场馆、价格

### 5. 智能推荐排期
- 筛选条件：**只看非工作日**（周末）、**只看 19:00 后**（晚场）
- 勾选后符合条件的场次标 **⭐ 绿色推荐**，显示「已按筛选推荐 N 场」
- 一眼看出哪天去看最合适

### 6. 抢票管理
- **待抢票列表**：开票时间秒级倒计时，开票前 30 分钟变红
- **已抢列表**：状态简化为「已购 / 放弃」
- 计划可**公开给社区**（他人可搜到并一键加入）

### 7. 社区共享 + 点赞
- 计划公开后进入社区库，他人搜索同名剧可命中
- 社区结果**按点赞数降序**（赞多 = 更可信）
- 点赞/取消、禁止自赞、隐私脱敏（不暴露分享者 userId/备注/个人状态）

### 8. 安全
- 服务端整站鉴权（登录后 7 天免登录）
- 默认访问密码可改（`web-version/sources/config.js` 的 `PASSWORD`）

## 🚀 本地启动

```bash
node web-version/server.js        # 默认端口 8878，被占用自动顺延
# 或 Windows 双击 web-version\启动网页版.bat
```

## ❓ FAQ

**Q：搜索为什么很多来源是 ⛔？**
A：大麦/猫眼/保利/360 对服务器 IP 反爬拦截，这是平台风控常态。系统用「官方剧院源（文化广场/大剧院）+ 社区共享」兜底，这两类数据是稳定可用的。

**Q：能爬微信小程序的数据吗？**
A：`#小程序://` 链接无法直接访问，需要抓包逆向其 API。官方剧院的 H5/官网（如文化广场、大剧院）反而是更稳的路径，已接入。

**Q：数据会同步吗？**
A：多用户版数据存服务器，**跨设备同步**；离线版存浏览器本地，不同步。

**Q：想加新的剧院数据源？**
A：给我剧院官网/购票 H5 地址，照文化广场/大剧院的逆向路径适配即可。
